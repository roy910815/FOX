# 狐狸桌寵
桌面小狐狸 (Desktop Fox Pet)
一款基於 Python 與 PyQt6 開發的輕量級桌面互動寵物。這隻小狐狸會生活在你的螢幕上，伴隨你工作與娛樂，並根據你的互動產生不同的情緒與行為反應。
# 功能特色
•	動態生存系統：狐狸擁有「飽食度」、「精力」、「心情」與「好感度」四項數值，數值會隨時間動態消耗。
•	多樣化行為模式：具備 閒置 (Idle)、走路 (Walk)、睡覺 (Sleep)、進食 (Eat)、驚訝 (Notice) 等多種動畫狀態。
•	全域召喚功能：在螢幕任何地方「雙擊滑鼠左鍵」，小狐狸會立刻察覺並奔向你的游標位置。
•	深度互動體驗：
o	拖拽與物理：可以隨意抓起狐狸移動，放開後狐狸會因重力下墜。
o	摸摸與撒嬌：滑鼠懸停在狐狸上半身可進行「摸摸」，好感度高時會觸發「翻肚子」動作。
o	蹭蹭提醒：當你太久沒理牠時，狐狸會主動跑過來蹭你的滑鼠。
•	控制中心：內建控制面板，可即時調整狐狸的大小比例、移動速度，並監看詳細數值。
•	自動存檔：程式會自動將狐狸的狀態保存於 fox_save.json，下次開啟時會接續之前的成長進度。

1. 必要需求

# 使用指南
動作	    說明
左鍵單擊拖拽	抓起狐狸移動位置。
全域雙擊桌面	召喚狐狸奔向你的滑鼠位置。
右鍵單擊狐狸	開啟選單（控制中心、過來這裡、餵食、關閉）。
滑鼠懸停頭部	持續 1 秒後觸發「摸摸」動畫，可提升心情與好感。
餵食	降低飢餓值（提升飽食度），並能強行叫醒睡覺中的狐狸。
# 數值邏輯
•	睡覺：當精力過低或飢餓值過高時，狐狸會進入睡眠。睡眠中會快速恢復精力，且體力與飽食度皆滿時會自動起床。
•	心情：長時間不互動心情會下降，心情低落時狐狸會更頻繁地尋求主人的關注。
•	好感度：透過餵食與摸摸累積，目前好感度設定為無上限。
